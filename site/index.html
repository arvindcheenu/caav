caav

Attach attention to any 3D object, record it per person, and show it back.

The toolkit from HeedVision, IEEE VIS 2026. CAAV stands for collaborative attention-aware visualization.

Docs Source on GitHub Try it Examples llms.txt AGENTS.md

Try it

Each view is one person looking at the same object, recording attention from their head direction. Give each person their own settings in the panel. Drag a view to steer that person, or focus it and use the arrow keys.

Examples

Built for the paper HeedVision: Attention Awareness in Collaborative Immersive Analytics Environments. Works with three.js, with optional React Three Fiber hooks. The core has no dependencies.

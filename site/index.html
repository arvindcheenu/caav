caav

    Attach attention to any 3D object, record it per person, and show it back.

    The toolkit from HeedVision. CAAV stands for collaborative attention-aware visualization.

    Docs Star caav on GitHub Paper llms.txt AGENTS.md

    Try it

    Each view is one person looking at the same object, recording attention from their head direction. Give each person their own settings in the floating panel, which you can drag by its title bar. Drag a view to steer that person, or focus it and use the arrow keys.
